# 🚚 Amazon Delivery Analysis — Power BI Dashboard

## 📊 Project Overview

This project analyzes Amazon delivery data using **Power BI** to understand delivery performance, order distribution, and operational factors affecting delivery time.

The dashboard transforms raw delivery data into interactive visualizations and business insights that can help identify areas for operational improvement.

---

## 🎯 Project Objectives

* Analyze overall delivery performance
* Track total orders and average delivery time
* Understand delivery performance across different areas
* Analyze order distribution by category
* Compare vehicle-wise order distribution
* Understand the impact of traffic and weather on delivery time
* Analyze delivery-agent performance

## 💡 Key Business Questions

The dashboard was designed to answer questions such as:

1. How many orders were delivered?
2. What is the average delivery time?
3. Which areas have longer delivery times?
4. Which vehicle is used for the most deliveries?
5. Which categories generate the most orders?
6. Does traffic affect delivery time?
7. Does weather affect delivery performance?
8. Does agent rating have a relationship with delivery time?
